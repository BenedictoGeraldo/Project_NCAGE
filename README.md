# 📝 Project NCAGE

**Project NCAGE** adalah sebuah website berbasis Laravel yang dikembangkan selama magang di **Pusat Kodifikasi Badan Sarana Pertahanan (Baranahan), Kementerian Pertahanan RI** 🇮🇩.

---

## 🛠️ Stack Teknologi

- ⚙️ Laravel `v10.48.29`
- 🐘 PHP `v8.3.23`
- 🐬 MySQL `v8.0.41`
- 🎨 Bootstrap `v5.0.2`
- 🌸 Filament `v3.3`
